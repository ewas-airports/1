Rule 7 – Aircraft by Departure / Destination

ICAO codes in each list trigger the proposed aircraft when they appear as either Departure or Destination (outbound and return flights). LSZH and LSGG are neutral and ignored for this rule. Every OFP route still requires manual aircraft confirmation. Enter comma- or space-separated ICAO codes; a code may only appear in one list.

Rule 8 – Official ASS Flow (automatic)

Automatic ASS requirement · Current = OFP DEP · Previous = FlyPad EX · Next = OFP DEST.

ASS required if Current is outside EU/EFTA, Canada and BEG; or if Previous is outside EU/EFTA, UK, Canada, USA, BEG and SIN; or if Next is in the USA. Otherwise ASS not required. Unknown ICAO classifications stay pending.

Airport classification is independent of A330/A350 AAL List 2. EU/EFTA, UK, Canada and USA use ICAO allocation prefixes with explicit territorial exceptions; prefix-based classification does not validate that an airport exists. Check the official flow before operational use.
